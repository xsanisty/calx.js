📖 Key Differences from jQuery Version

✅ No jQuery Required

Uses native ES modules and DOM APIs - lightweight and modern

🎯 Direct API Access

Full programmatic control via Calx.createWorkbookFromElement()

🔧 Manual Updates

DOM updates require explicit code - gives you full control

🛠️ Basic Usage Pattern

<!-- HTML with data attributes -->
<div id="calculator">
    <input data-cell="A1" value="10" />
    <input data-cell="A2" data-formula="=A1*2" />
</div>

<!-- ES Module Script -->
<script type="module">
    import { Calx } from '../dist/calx.esm.js';

    const element = document.getElementById('calculator');
    const workbook = Calx.createWorkbookFromElement(element);

    console.log('Workbook created!', workbook);
</script>
