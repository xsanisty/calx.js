CalxJS jQuery Thin Build Example

About jQuery Thin Build

This example uses the jQuery thin build of CalxJS, which excludes the FormulaJS library. Both jQuery and FormulaJS are loaded separately from CDN, reducing the CalxJS bundle size from ~330 KB to approximately ~202 KB (39% reduction).

Load order: jQuery → FormulaJS → CalxJS (thin)
