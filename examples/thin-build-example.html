CalxJS Thin Build Example

About Thin Build

This example uses the thin build of CalxJS, which excludes the FormulaJS library. The FormulaJS library is loaded separately from CDN, reducing the initial CalxJS bundle size from ~323 KB to approximately ~195 KB (40% reduction).

Load order: FormulaJS must be loaded before CalxJS.
